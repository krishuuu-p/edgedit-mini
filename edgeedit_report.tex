\section{Goal and Reproduced Method}
EdgeDiT~\cite{edgedit} compresses a Diffusion Transformer (DiT) through
\textit{hardware-aware surgery}: block removal, MLP-ratio reduction, and
hidden-dimension reduction. This work implements the same EdgeDiT workflow at
reduced scale: feature-wise knowledge distillation (FwKD), surrogate assembly,
hardware-aware Pareto selection, and end-to-end fine-tuning.

The experiment uses FashionMNIST ($28\times28$), a class-conditional 6-layer
Tiny-DiT teacher (hidden size 128; 1.875M parameters), and an RTX 3050. The
quality run trains the teacher for 30K steps, distils the surrogate library for
1.6K steps per surrogate, evaluates 60 assembled candidates, and fine-tunes two
selected Pareto-optimal models for 15K steps. The pipeline follows the paper:
selected Pareto-optimal models for 15K steps. The pipeline follows the paper's
surrogate-distillation and end-to-end training stages:

\begin{center}
\scriptsize
\textbf{Teacher} $\rightarrow$ \textbf{FwKD surrogates} $\rightarrow$
\textbf{candidate assembly} $\rightarrow$ \textbf{latency-quality Pareto search}
$\rightarrow$ \textbf{fine-tuning}.
\end{center}
\vspace{-0.45em}

As in EdgeDiT, FwKD trains each substitute to match its corresponding teacher feature. The
candidate library contains: (i) a block-removal surrogate that replaces two
consecutive blocks with one, (ii) MLP-ratio $r=4\rightarrow2$ surrogates, and
(iii) hidden-dimension $d=128\rightarrow64$ surrogates. Sensitivity checks
showed progressively worse samples with more merged pairs; reduced MLP and
hidden dimensions remained usable, motivating their inclusion in the search.

\section{Latency-Aware Architecture Selection}
Following EdgeDiT's bi-objective model-selection formulation, candidates were
ranked by measured RTX 3050 denoising-step latency and proxy feature MSE.
\textbf{EdgeDiT-small} is the fastest non-dominated model; \textbf{EdgeDiT-large}
is the lowest-error model on the latency-aware Pareto front.

The reduced-scale implementation reproduces EdgeDiT's central quality-efficiency
trade-off.
\textbf{EdgeDiT-small} has \textbf{47.5\% fewer parameters} and is
\textbf{2.27$\times$ faster} than the teacher, at the cost of higher Proxy-FID.
\textbf{EdgeDiT-large} achieves the best quality: Proxy-FID falls from 9.506
to \textbf{5.742} (a \textbf{39.6\% reduction}), while it is still
\textbf{1.54$\times$ faster} and uses fewer parameters than the teacher.

\section{Why FwKD Matters}
The FwKD ablation fixes the EdgeDiT-small architecture and changes only its
initialization. Distilled surrogate initialization produces noticeably more
structured samples than random initialization, confirming that local feature
matching is useful before end-to-end fine-tuning.

\section{Conclusion and Scope}
This implementation reproduces the paper's core method: local surrogate
distillation plus hardware-aware architecture search can yield compact diffusion
transformers with meaningful quality-efficiency trade-offs. The implementation
changes only the experimental scale and evaluation environment: Proxy-FID uses
FashionMNIST CNN features, and latency is measured on an RTX 3050. Therefore,
the resulting values are not directly comparable to EdgeDiT's ImageNet FID-50K
or mobile-NPU measurements.
